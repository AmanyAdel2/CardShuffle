# 🃏 CardShuffle

A slick, interactive 3D card shuffling stack built with **SwiftUI**. Swiping down on the top card moves it smoothly to the back of the stack using natural spring animations.

## ✨ Features

- **Fluid Gestures:** Smooth dragging powered by SwiftUI's `DragGesture`.
- **3D Depth & Perspective:** Cards dynamically adjust scale, vertical offset, and depth ordering (`zIndex`) based on their stack position.
- **Customizable Card Design:** Built with modular subviews for easy styling and customization.
- **Spring Physics:** Interactive bounce-back and swipe animations using `.spring()` timing curves.
